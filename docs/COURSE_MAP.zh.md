# SciFact 对应的课程知识

按提供的 MIAZ01《AI Technology and Applications》大纲，项目结合了大语言模型、提示工程、检索增强生成、微调与性能评估。分类器是 Qwen，任务是判断科学声明属于支持、反驳还是证据不足。

## 已经做过的实验

| 项目步骤 | 对应专业知识 | 在项目里怎么用 |
|---|---|---|
| C0 闭卷 | 大语言模型、提示工程、分类基线 | 只给模型声明和任务提示，先测不提供论文时的准确率。 |
| C1 检索摘要 | RAG（检索增强生成）、信息检索 | 先用 BM25 和 BGE 找相关论文，再把摘要交给模型判断。 |
| C2 选句 | RAG 上下文筛选、证据检索 | 从摘要筛选证据句。输入更短，但本次准确率也从 56.0% 降到 47.3%。 |
| C3 微调 | 监督微调、LoRA、QLoRA、量化 | 用 809 条有人工标签的训练声明学习分类。基础模型以四位量化加载，训练低秩适配器。 |
| C4 证据说明 | 提示工程、两阶段推理、可解释性 | 先写带引用的证据说明，再用同一适配器判标签。 |
| C5 拒答 | 模型置信度、校准、选择性预测 | 用一组数据设定拒答规则，再用另一组数据测回答比例和错误率。这里使用 split conformal，它是项目对课程性能评估主题的延伸。 |
| 对照、证据替换和结果统计 | 控制变量、模型鲁棒性、分类评估 | 每次改一个条件，比较准确率和宏平均 F1；替换证据句，观察模型的判断是否随之改变。 |

课件 IV–VI 可对照 PDF 第 5 页的 LoRA、第 12 页的 QLoRA、第 37 页的两阶段推理和第 49–53 页的 RAG。模型名称、检索算法和具体评估规则由项目自行选择。

## 后续验证对应的知识

| 验证工作 | 对应专业知识 | 要回答的问题 |
|---|---|---|
| 人工误差复核 | 定性错误分析、错误分类 | 是检索没找到论文、选句漏了证据，还是模型看了证据也判错？ |
| 多种子复验 | 可重复性、随机性、均值与波动 | 保持数据和设置固定，换两个随机种子重训，C3 的提升是否稳定？ |
| SciFact-Open 全库实验 | 泛化、分布变化、检索规模 | 保持模型和规则不变，把检索范围扩大到更大的论文库，找证据和分类的表现会变多少？ |
| 完整秩消融 | LoRA 低秩适配、控制变量、资源取舍 | 只改适配器秩，比较 8、16、32 三档的准确率、耗时和显存。 |
| 英文报告和答辩 | 研究设计、结果解释、技术写作 | 能否说明研究问题、数据划分、每组改动、主要发现和局限？ |

复验和误差分析是通用研究方法。C3 三种子准确率为 64.7%–65.3%；六档消融中，BF16 秩 8 单次测得 67.3%。这些数字来自同一批留出开发样本。课纲和提案没有设定 90% 的模型门槛。
