# 为什么 C2 选句后有些题答错了

这 10 条来自 SciFact dev 的留出评估半组，由 AI 根据缓存的 C1、C2 预测和语料逐条对照，供课程报告解释。E8 人工复核与标注一致性需要由复核者独立完成。这些案例按现象选取，各类占比见 [E2 统计表](../outputs/tables/e2_selection_audit.md)。

C1 和 C2 检索到的论文相同。C1 把摘要前部和标题交给判定模型。C2 改用相关性模型挑出的少量句子。以下的箭头表示 C1 到 C2 的预测变化。`SUPPORT` 表示支持，`REFUTE` 表示反驳，`NEI` 表示证据不足。句子编号为 `文档ID#句子索引`，其中索引从 0 开始。

## 找到了论文，选句时漏了参考证据

- **1121｜突触活动是否促进突触后树突局部释放 BDNF**。参考标签是 `SUPPORT`，预测为 `SUPPORT → NEI`。C1 包含 `4456756#7`，该句明确描述受刺激的树突棘释放 BDNF。C2 选了突触活动、突触可塑性和神经递质释放相关的句子，例如 `29745822#0`，但 4 句都来自其他论文，遗漏了参考句。
- **1337｜UBC13、K63 型多聚泛素链和 PCNA 的关系**。参考标签是 `SUPPORT`，预测为 `SUPPORT → NEI`。C1 包含同一句中关联这三个要素的 `20231138#4`。C2 从该论文挑了描述 PCNA 泛素化的背景句 `20231138#0`，另两句介绍泛素化的一般作用，机制细节丢失。
- **598｜细胞学筛查是否使宫颈癌发病率上升**。参考标签是 `REFUTE`，预测为 `REFUTE → NEI`。C1 包含 `25742130#6` 和 `#9`，谈到发病率下降和死亡率下降与筛查的关系。C2 从这篇论文选了背景句 `25742130#0`，另选的 `6561200#7` 对比两种筛查方法的检出敏感度，关注的指标和主张里的发病率不同。

## 保留了完整参考证据，判定仍然变错

- **1339｜超声引导是否增加创伤性穿刺**。参考标签是 `REFUTE`，预测为 `REFUTE → NEI`。C1 有 `15482274#9`，报告创伤性操作风险下降及其数值。C2 保留了可独立构成一组参考证据的结论 `15482274#10`，同样说创伤性穿刺的风险可降低。这条适合检查模型能否识别「增加」和「降低」的方向冲突。
- **1150｜Tetraspanin-3 与急性髓系白血病的发生**。参考标签是 `SUPPORT`，预测为 `SUPPORT → NEI`。C2 保留 `11369420#4`，说明在小鼠模型中敲除该蛋白会抑制白血病干细胞自我更新和疾病传播。C1 还包含论文标题、人源样本的 `#5` 和总结句 `#7`。这里的区别包括模型对单句证据的判读，以及同一论文的标题和后续结果是否一起呈现。
- **852｜常规治疗反应不足时是否应减少无创通气**。参考标签是 `REFUTE`，预测为 `REFUTE → NEI`。C2 保留 `13843341#10`，该句总结了无创通气对成本和院内死亡率的益处，属于一组完整参考证据。C1 还包含 `13843341#3` 和 `#6`，给出入组人群和两组死亡人数。摘要里的研究对象、比较组和结论一起提供了更具体的背景。

## 选句后与参考标签一致的案例

- **742｜大环内酯类药物对心肌梗死没有保护作用**。参考标签是 `SUPPORT`，预测为 `NEI → SUPPORT`。C1 和 C2 都包含 `32159283#8`，该句报告大环内酯类药物的既往使用未见影响。C2 把这句作为唯一输入证据，缩短上下文后判对了。主张里的「没有保护作用」正是该条证据支持的内容。
- **880｜长链非编码 RNA 的核糖体占据与 5′ UTR 类似**。参考标签是 `SUPPORT`，预测为 `NEI → SUPPORT`。两组都能看到 `8426046#3`。该句明确比较核糖体占据，C2 把它排在第一句，随后保留同一论文的 `#2` 作为背景。
- **232｜白内障和沙眼是否是南苏丹失明的首要原因**。参考标签是 `NEI`，预测为 `SUPPORT → NEI`。C1 的多个摘要分别谈到南苏丹沙眼和全球白内障负担。C2 的 `7655029#1` 只称沙眼是当地失明的严重原因，`10536636#2` 描述研究目的。用这些句子判断两种病因是否共同居首，证据不足，C2 与标注一致。这里的结论范围限于提供的句子和数据集标注。

## 空上下文也会给出肯定结论

- **1200｜ML-SA1 在 hTRPML2 和 hTRPML1 的结合朝向是否不同**。参考标签是 `NEI`，预测为 `NEI → SUPPORT`。C1 检索列表的第一篇 `11420613` 是关于核糖体蛋白基因调控的论文。C2 选中 0 句，模型仍输出 `SUPPORT`。这个例子适合单独检验缺少上下文时，系统是否会遵守证据约束。

参考句编号来自数据集标注。别的句子也可能提供相关或补充信息，因此检查选句覆盖率和检查最终判定需要分别进行。可从 `claims_dev.jsonl`、`corpus.jsonl` 和 `c1_dev.jsonl`、`c2_dev.jsonl` 按上述编号复现。
